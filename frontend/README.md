# SignalGraph Frontend

Interactive hackathon demo for **SignalGraph: Business Brain**.

## Friday demo slice

- **Metric:** NRR (3-month)
- **Cohort:** Oct/Nov 2024 conversion cohorts
- **Story:** NRR drop driven by lower JPay activity and onboarding completion
- **Data:** Mock data only (Option A)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Views

1. **Answer** — verdict, top drivers, cohort comparison
2. **Causal graph** — interactive DAG with Walk Backwards
3. **Evidence** — charts, timeline, counterfactual, recommendations

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- React Flow (`@xyflow/react`)
- Recharts
- Lucide React
