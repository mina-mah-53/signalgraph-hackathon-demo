# SignalGraph

Hackathon project for autonomous metric monitoring, causal explanation, and forecasting.

## Structure

```
signalgraph/
├── frontend/   # Interactive demo UI (React + Vite)
└── ...
```

## Run the demo UI

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

See [frontend/README.md](frontend/README.md) for demo details and stack.
